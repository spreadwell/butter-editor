# 0.11.1

- Updated licensing compatibility so Butter Editor can accurately reflect server-managed trial dates, trial durations, and per-license device limits while preserving existing keys and sessions.
- Hardened license refresh handling so revoked licenses and upgrade-required trial sessions cannot regain access from cached offline state.
- Preserved Obsidian file breadcrumbs when switching into and out of Butter Editor.
- Restored block-selection highlights across Obsidian windows and bottom-toolbar layouts, with fade-only dismissal and reduced-motion support.
- Kept block drag handles visible with a bottom toolbar and prevented hidden handles from intercepting clicks.
- Kept table-cell selection frames clear of top chrome in both toolbar layouts.
- Prevented unexpected upward-drop scrolling on desktop and corrected its scroll anchor on iOS.
