# Butter Editor 0.9.6

- Save failures now show a notice when something blocks the write (disk full, sync lock, dropped network drive). Previously they failed silently.
- Third-party plugins that throw while rendering inside Butter no longer take the view down with them. Their errors land in Butter's error log.
- Two commands renamed: `Toggle Butter Editor mode` is now `Toggle WYSIWYG mode`. `Open current note in Butter Editor` is now `Open current note in WYSIWYG view`. Re-bind shortcuts if you had them on either.
- Minimum Obsidian version is now 1.7.2.
- Disable / uninstall now leaves no trace behind.
