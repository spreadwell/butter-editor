# Butter Editor 0.9.8

- `authorUrl` in the manifest now points at the Spreadwell GitHub profile instead of the plugin's own repo. Addresses a directory review warning.
- Release artifacts (`main.js`, `styles.css`) now ship with GitHub build-provenance attestations. Anyone downloading from BRAT or the directory can cryptographically verify the files came from this repo at this commit.
- Replaced the `builtin-modules` build dependency with Node's built-in `module.builtinModules` to drop a deprecated package.
- CSS hardening pass: removed 14 unneeded `:has()` queries and `!important` declarations (down from the directory review baseline), consolidated 6 duplicate selectors, fixed a duplicate `white-space` declaration, expanded short-form hex colors to 6 digits, replaced unsupported font-family keywords with their generic fallback, collapsed `text-decoration` shorthand. The `:has()` replacements now route through ancestor classes that JS toggles on the toolbar / suggester / modal hosts when the relevant child appears — equivalent behavior, lint-clean cascade.
