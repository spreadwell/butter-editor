# 0.12.0

## New features

- Find and replace text without leaving your note, with regular expressions and navigation that reveals results inside folded sections.
- Use a customizable context menu for formatting, insertion, Obsidian commands, and compatible plugin actions. Correct spelling or add words to your dictionary directly from the menu.
- Collapse and expand heading sections and native callouts, respecting callout `+`/`-` defaults while preserving Markdown.
- Resize standalone images and move images between inline and block placement with clearer drop feedback.
- Send bug reports and feature requests from Help & feedback in settings.
- Explore the in-app What's New page with release demos, automatic opening after upgrades, a dismissible settings card, and permanent access from Support settings.

## Improvements

- Keep your place when switching between Butter, Source, Live Preview, and Reading.
- Find settings in focused sections, and customize desktop and mobile toolbars with presets, submenus, and command palette actions.
- Edit note links and web links through desktop popovers and mobile drawers.
- Write with improved slash commands, list indentation, Properties suggestions, footnotes, and inline Markdown shortcuts.
- Move blocks with smoother reflow, clearer nesting feedback, compact previews, and more stable placement in nested containers and at their boundaries.
- Enjoy more responsive rendering in large notes and long sessions, with stronger save, reopen, multi-pane, file-switching, and external-change handling.
- Improved accessibility semantics and settings discoverability in newer Obsidian versions.

## Fixes

- Converting selected text to a bullet list preserves its content and selection.
- Explicit `<br>`, `<br/>`, and `<br />` tags render as line breaks.
- Find/replace preserves surrounding inline content and line breaks; expensive regular expressions time out without blocking editing.
- More stable list markers, task checkboxes, block selection, and nested drag geometry.
- More predictable keyboard dismissal, disclosure controls, and link editing on iOS.
- Safer date-only values in datetime Properties and stronger Markdown preservation across formatting, paste, undo, redo, composition, tables, callouts, links, embeds, and plugin syntax.
- Cleaner spacing, icons, responsive layouts, and presets.
