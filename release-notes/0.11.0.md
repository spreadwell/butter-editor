# 0.11.0

- Added localized UI for Simplified Chinese, Traditional Chinese, Japanese, Korean, Spanish, German, French, Portuguese, Brazilian Portuguese, and Russian.
- Added automatic language matching with Obsidian and a manual language selector in Butter Editor settings.
- Redesigned the welcome walkthrough for clearer setup on desktop and mobile.
- Improved first-run choices for rich formatting and Markdown typing shortcuts.
- Refined settings notices, experimental indicators, spacing, and Obsidian 1.13 compatibility.
- Improved mobile onboarding layout, safe-area handling, and narrow-screen license actions.
- Fixed a trial activation race that could produce an unnecessary polling error after successful activation.
- Prevented repeated onboarding actions from launching duplicate trial or purchase flows.
