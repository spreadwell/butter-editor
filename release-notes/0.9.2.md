Mobile fixes, plus a locked-file view.

- Tapping a note from the mobile file sidebar now reliably opens it in Butter. The "Open notes in Butter" setting is on by default.
- The top header and bottom navbar hide when you scroll down and reappear when you scroll up. Backgrounds blend with the editor so there's no visible boundary line.
- Hide-keyboard button added to the mobile toolbar.
- If you've turned off "Show inline title" in Obsidian, Butter respects that on mobile now. Reclaims about 1.5em at the top of the note.
- If another process is holding a file open (a sync engine mid-write, for example), Butter shows a read-only view instead of failing to load it.
