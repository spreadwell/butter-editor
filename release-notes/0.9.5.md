# Butter Editor 0.9.5

- **Source is now public.** Butter has moved from closed-source to source-available. The source lives in this repository under the [Butter Editor License](../LICENSE), which permits private use, internal organizational use, and bespoke client-specific implementations, but restricts use as a substantial component of a general-purpose competing Obsidian product.
- **Why this matters.** Source-available is the path into the official Obsidian community plugin directory. Butter can move out of BRAT-only distribution and reach users who only install directory plugins. Anyone can also verify what Butter does with your notes (the answer remains: edits in place, no content ever leaves your machine).
- **Zen mode removed.** The internal "distraction-free" toggle that hid the ribbon, status bar, and view header is gone. Use Obsidian's built-in focus / hide-UI commands instead.
- **Live-source view removed.** The optional right-sidebar pane that mirrored the active note's markdown source in real time is gone. Obsidian's native Source mode is enough.
- **README refresh.** Plainer language. Round-trip safety and mobile each got their own section.
