# 0.10.4

- Added a setting for Markdown typing shortcuts. Shortcuts are now off by default for a more visual editing feel.
- Improved typing of literal Markdown characters such as asterisks, underscores, and hashes.
- Fixed bold, italic, and other formatting hotkeys in Butter views.
- Fixed Obsidian's mode toggle command while Butter is active.
- Improved tag, wikilink, and slash autocomplete popup styling, positioning, and dismissal behavior.
- Added inline creation support for new tag and wikilink suggestions.
- Fixed toolbar dropdowns and color pickers opening off-screen near the bottom of the window.
- Improved detached toolbar sizing on desktop.
- Fixed mobile link handling, including external link creation and keyboard behavior when tapping links.
