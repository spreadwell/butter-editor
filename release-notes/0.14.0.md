# 0.14.0

- Use autocomplete suggestions from other plugins, such as dates and word completion, and accept them with Enter or a click.
- Insert templates, dates, and other plugin text at the cursor, including on a new empty line, and undo each insertion in one step.
- When the Tasks plugin is installed, checking a task box adds its done date and next recurrence, as in Live Preview.
- Keep text you didn't edit exactly as written. Source preservation is now on for everyone and can be changed under Settings → Butter Editor → Advanced.
- Stop adding backslashes to lines you didn't edit when saving.
- Keep notes with unsupported inline HTML, such as custom tags, editable; only the block that contains it stays as written.
- Open other plugins' suggestions only as you type, including after switching a note from Live Preview to Butter.
- Keep the drag handle aligned on a new empty line.
- Update notes changed by another plugin without replaying the opening animation.
