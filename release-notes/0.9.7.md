# Butter Editor 0.9.7

- Plugin author is now "Spreadwell" so the plugin browser shows "Butter Editor by Spreadwell" instead of "Butter Editor by Butter Editor".
- Brand icon is now the Butter wave-glyph mark instead of the generic Lucide placeholder. Appears in the mode-cycle button and the View-as menu.
- Removed two undocumented syntax extensions that shipped by accident as part of internal API dogfooding. The `::: spoiler` collapsible block and the `@username` mention atom no longer render. Neither was documented or supported. If you were relying on either, open an issue and we can talk through a real feature path.
