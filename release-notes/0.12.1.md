# 0.12.1

- Link suggestions no longer appear twice and close when you press Escape, click outside, or move focus away.
- Converting selected lines to a list preserves the text and respects soft line breaks.
- Backspace and Delete preserve continuation text, nested items, spacing, and Undo/Redo when joining list items.
- Enter replaces selected text and splits the surrounding list item as expected.
- Tab and Shift+Tab indent or outdent selected list items together.
- Restored mobile notes refresh toolbar availability when editing resumes.
- Updated Markdown and editor dependencies to address security advisories.
