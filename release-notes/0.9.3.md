Compliance pass for submitting Butter to Obsidian's community plugin store.

- Default hotkeys for find (Ctrl/Cmd+F), replace (Ctrl/Cmd+H), and shortcuts (Ctrl/Cmd+/) are gone. Obsidian's submission rules don't allow defaults that can collide with your own bindings. Set them yourself in Settings > Hotkeys if you want them back.
- README now lists every Butter Editor domain the plugin contacts (license validation, customer portal, marketing site).
- Internal compliance fixes: file existence checks go through the Vault API, clipboard HTML is parsed with DOMParser.
